# 积留的判断

每一列天气是独立情景。先看能否到达，再看能否留住。斜面、粗糙的凹口、伞下地面和竖直表面在不同天气下会有不同结论。

| 情景 | 会积的典型部位 | 排除或保守处理 |
| --- | --- | --- |
| 普通降雪 | 树冠外层叶簇上侧、朝上的枝杈、桌板、横栏顶和露天地面 | 直立树干侧面、枝下、桌腿、檐底和无遮挡物的天空。棚下即使平坦也排除直接落雪。 |
| 雨后积水 | 有直接来雨或上游来水、又能存住明水的凹面、轮辙或堵塞排水口 | 立面和排水顺畅的坡面仅湿润。草尖的水珠不算水洼。 |
| 结霜 | 假定潮湿冷夜，达到霜点且低于冰点的外露草叶、冷金属或玻璃表面，也可包括立面 | 持续温热的表面排除。树荫、屋檐影响热交换，不能仅凭雨淋不到就断定无霜。 |
| 凝露 | 高于冰点且冷却到露点的草尖、叶缘、玻璃、金属表面 | 温热面排除。凝露部位可以竖直。 |
| 冻雨挂冰 | 过冷雨滴能打到、接触后能冻结的枝、立柱、栏杆上沿和迎雨侧 | 避雨的背面和保持温暖的面排除；竖直树干迎雨一侧可以挂冰。 |
| 积水再冻结 | 先前留有水的冷地面、浅洼和潮湿面；先前淋湿的立面同样可能结薄冰 | 干面排除；开阔水域默认短时过程尚不足以封冻。 |
| 冰雹堆积 | 能接住或拦住滚落冰粒的浅坑、沟底、路缘内侧 | 无阻挡的斜屋面、桌边、直立树干排除。撞击处与最后停留处可在不同区块。 |

## 空间修订

画面内清楚可辨的部位可以覆盖自动结果。单图用 --patches 文件；批量用 --reviews 目录，文件名是该 manifest.json 原始字节的 SHA-256 加 .json。未提供修订的照片运行自动估计。每份文件的 size 是绘制多边形时显示的完整正向原图宽高；不能包含图例、留白或裁切。polygon 是左上角起算的整数坐标，按比例映射原尺寸，与指定 region_id 取交集。同一区域后面的多边形优先。同一部位的多个轮廓可共用相同名称和属性。下例编号和坐标仅示意。

```json
{
  "manifest_sha256": "当前分区清单指纹",
  "size": [900, 600],
  "assumptions": ["车辆停放，车身已冷却，风挡温度未知。"],
  "patches": [
    {"region_id": 6, "polygon": [[246,278],[372,278],[386,305],[360,336],[251,326]],
     "name": "前引擎盖上表面", "kind": "solid", "direct": true, "holds_snow": true,
     "pools": false, "inflow": false, "traps_hail": false, "freezes": true,
     "wet": true, "frost_ready": true, "dew_ready": true}
  ]
}
```

仅提供当前情景有依据的属性，未知字段值用 null 或省略；省略不等于 false。一个完全遮挡的表面仍可能从别处接水。上游天空、信息栏和开阔水面保持各自的保护规则。归属模糊的原尺寸边界返回 127。

## 自动估计与具名部位

命令自动使用上游的真实分区和本地单目相对深度。用近邻采样读取 部位编号.png 的原始整数，按 locations.parts 匹配部位名称；坐标已应用 EXIF 方向，使用原图区块边界裁剪。指定多个天气会复用同一份几何。没有可靠证据时的「保守略过」是最终处理意见。

需要修正几何或表达更确切的名称时，由运行技能的 agent 编写一份绑定 manifest.json 文件 SHA-256 的 parts.json，带 --parts 运行。此模式通过位置描述和 region ID 交接，适合指代明确的具名部位。覆盖清单的每个区块，局部命名能定位到画面。下例仅示意一个树区块。假设写入 assumptions。

```json
{
  "manifest_sha256": "清单文件字节的 SHA-256",
  "assumptions": ["普通降雪，弱风，树体足够冷。"],
  "parts": [
    {"region_id": 4, "name": "左侧树冠外层朝上的叶簇", "kind": "solid", "direct": true, "holds_snow": true},
    {"region_id": 4, "name": "左侧直立树干侧面", "kind": "solid", "holds_snow": false}
  ]
}
```

kind 可为 solid、water、air 或 unknown。只填写对应天气需要的布尔属性。direct 指降水可直接抵达，holds_snow 指能承雪，pools 指可蓄明水，inflow 指另有来水，traps_hail 与 inflow_hail 分别指能截留冰粒及有冰粒滚入。frost_ready 与 dew_ready 已包含湿空气与表面温度条件。freezes 指表面足够冷且持续到水冻结，wet 指降温前已湿，water_freezes 专用于水体封冻。缺少决定性属性时保守略过，禁止把猜测的枝条写成照片中已识别的枝条。

## 模型依据

降雪分别判断「能否抵达」和「到达后能否稳定停留」，借鉴 Fearing 的积雪模型。程序通过本地 Depth Anything V2 获取单张照片的相对深度，在图像平面估计可见面的朝向和遮挡。[积雪模型](https://www.cs.ubc.ca/labs/imager/th/2000/Fearing2000/) · [Depth Anything V2](https://github.com/DepthAnything/Depth-Anything-V2)
